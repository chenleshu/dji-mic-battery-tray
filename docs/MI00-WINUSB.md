# MI_00 WinUSB 安全配置说明

大疆麦克风电量 2.0 只有在 DJI USB 接收器的 Interface 0（`MI_00`）使用 WinUSB 时，才能在 Windows 处理音量命令之前读取连接键，从而彻底避免系统音量变化和音量浮层。电量显示本身不依赖这一步。

## 重要边界

- 只允许更改硬件 ID 含 `USB\VID_2CA3&PID_4011&MI_00` 的 Interface 0。
- 绝不能选择父设备 `USB\VID_2CA3&PID_4011`。
- 绝不能更改 `MI_01`；它是 USB Audio，替换后麦克风会无法正常录音。
- `MI_06` 是本软件读取 USB 电量的独立接口，保持其现有 WinUSB 配置。
- 正式包不包含本项目自制的驱动签名脚本。Zadig/libwdi 会为选中的设备即时生成自签名证书，把证书加入本机 Root 与 Trusted Publishers，并在签署目录后立即销毁私钥；证书公钥会保留。完整机制见 [libwdi 官方证书实践说明](https://github.com/pbatard/libwdi/wiki/Certification-Practice-Statement)。
- 如果不接受上述系统证书变更，请不要配置 `MI_00`，只使用电量显示功能。

## 安装

1. 从 [Zadig 官方网站](https://zadig.akeo.ie/) 下载工具。运行前在文件属性的“数字签名”页确认签名者为 `Akeo Consulting`。
2. 插入 DJI USB 接收器，退出可能正在占用接收器的 DJI 工具。
3. 以管理员身份运行 Zadig，打开 `Options > List All Devices`。
4. 在设备列表中选择 DJI 接收器的 Interface 0。名称可能随驱动状态变化，必须在设备属性中再次核对硬件 ID 含 `VID_2CA3&PID_4011&MI_00`。
5. 右侧目标驱动选择 `WinUSB`，然后执行 `Install Driver` 或 `Replace Driver`。
6. 安装完成后，以管理员身份打开 `certlm.msc`，在“受信任的根证书颁发机构”和“受信任的发布者”中找到主题包含本设备完整硬件 ID 且标为 libwdi autogenerated 的证书，记录主题与 SHA-1 指纹，供以后精确清理；不要修改其他证书。
7. 拔插接收器并运行“大疆麦克风电量”。在 `%LOCALAPPDATA%\大疆麦克风电量\status.txt` 中确认：

```text
连接键驱动=ok
连接键监听=ok
系统音量拦截=source_blocked
```

8. 确认 Windows 录音仍正常；设备管理器中 `MI_01` 的服务应仍为 `usbaudio`。

程序会读取每个 `MI_00` 设备实例注册的接口 GUID，因此不要求 Zadig 生成某个固定 GUID；枚举到的路径仍会再次严格核对 DJI VID/PID 与 `MI_00`。

## 恢复 Microsoft HidUsb

1. 退出“大疆麦克风电量”。
2. 打开设备管理器，按硬件 ID 找到 `USB\VID_2CA3&PID_4011&MI_00` 对应设备。
3. 选择“卸载设备”；若出现“尝试删除此设备的驱动程序”或同义复选框，请勾选。
4. 拔下并重新插入接收器，让 Windows 按设备原始 HID 描述符恢复 Microsoft `HidUsb`。
5. 再次核对 `MI_01` 仍为 USB Audio，麦克风录音正常。

如果 Windows 仍优先使用之前的 WinUSB OEM 驱动包，请在设备管理器的驱动详情中记录其精确 `oemNN.inf`，再以管理员身份执行 `pnputil /delete-driver oemNN.inf /uninstall`。不要删除名称不确定的驱动包。

恢复驱动后，如需同时清理 Zadig/libwdi 留下的设备专用证书，请以管理员身份打开 `certlm.msc`，分别检查“受信任的根证书颁发机构”和“受信任的发布者”。只删除主题明确包含本设备完整硬件 ID `USB\VID_2CA3&PID_4011&MI_00` 且标为 libwdi autogenerated、并与安装时记录指纹一致的证书；不要按模糊名称批量删除任何证书。
