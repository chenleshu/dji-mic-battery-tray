## 大疆麦克风电量 v2.0.1

v2.0.1 修复登录后自动启动的状态判断与安装验收问题。电量读取、蓝牙与 USB 双接入、多麦克风显示、连接键映射和 Typeless 自动回车逻辑保持不变。

### 自动启动修复

- 自动启动从 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 改为当前用户的 Windows 登录计划任务，避免 Windows 已跳过启动项、软件菜单却仍显示已启用的不一致状态。
- 托盘菜单名称改为“登录后自动启动”。菜单会核对任务是否启用，以及当前用户、登录触发、普通权限交互令牌、执行路径、启动参数和工作目录是否完整匹配。
- 任务定义只允许一个当前用户登录触发器和一个程序动作，拒绝错误主体、额外触发器或额外动作；菜单打开或用户修改设置后会重新同步真实任务状态。
- 修复计划任务尚不存在时，Task Scheduler 返回 `FileNotFoundException` 并导致状态检查失败的问题。任务不存在现在表示“未启用”；其他异常不会被吞掉。
- 登录任务在当前用户登录后延迟 10 秒启动，使用普通权限，不因电池供电而停止，并拒绝启动第二个实例。
- 旧版同名 `Run` 启动值会被删除，不再同时保留两套自动启动方案。

### 安装与卸载

- 默认安装位置改为：

  ```text
  %LOCALAPPDATA%\DjiMicBatteryTray\DjiMicBatteryTray.exe
  ```

- 安装器会在当前用户桌面创建“大疆麦克风电量”快捷方式，并核对快捷方式目标。
- 安装器会创建并完整校验登录计划任务，然后受控启动一次该任务。
- 受控启动后，安装器在 30 秒内核对只存在一个安装路径下的程序进程，并从新生成的状态文件校验版本、进程 ID、进程路径、`autostart` 启动来源和任务启用状态；任一条件不成立都会终止安装并报告错误。
- 卸载器会删除登录计划任务、旧版同名 `Run` 启动值、由安装器创建的桌面快捷方式、程序安装目录和本机状态目录。
- 卸载器删除任务前会核对根任务目录、动作路径、参数和工作目录；同名但不属于本程序的任务或 `Run` 值不会被误删。
- 直接下载并双击独立 EXE 仍可使用，但不会自动完成安装、快捷方式和登录任务配置；需要这些功能时请使用完整包中的安装脚本。

### 验证结果与边界

- 当前 Windows 11 已实机完成安装、任务定义完整性校验、受控任务启动、唯一进程检查和状态文件回执验证。
- 已确认受控启动的进程来自 `%LOCALAPPDATA%\DjiMicBatteryTray\DjiMicBatteryTray.exe`，并以 `--autostart` 标记启动来源。
- 本次没有注销或重启 Windows，因此没有把真实的下一次登录触发声明为已验证。受控任务启动链已经验证；登录触发仍需在用户下次登录 Windows 时观察。
- 本版本没有更改 WinUSB 驱动范围：`MI_01` USB Audio 保持不变，`MI_00` 继续用于连接键拦截，`MI_06` 继续用于 USB 电量读取。
